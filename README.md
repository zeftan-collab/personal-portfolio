# Personal Portfolio — Zofia Elisse F. Tan

A responsive personal portfolio website for a 4th-year BSIT student at La Consolacion University Philippines (LCUP). It showcases my background, technical skills, projects, and achievements.

**Live site:** https://YOUR-PROJECT.vercel.app

## Sections

- **Home** – name, introduction, and tagline
- **About Me** – personal introduction and educational background
- **Skills** – interactive technical skill categories
- **Projects** – Campus Lost and Found System, Student Attendance Monitoring, Café Website Design (Figma)
- **Achievements** – certifications, digital badges, seminars and webinars
- **Contact** – email, phone, and a contact form

## Built With

- HTML5
- CSS3 and [Tailwind CSS](https://tailwindcss.com/) (CDN)
- JavaScript (vanilla)
- [Font Awesome](https://fontawesome.com/) icons and Google Fonts

## Run Locally

1. Clone the repository: `git clone https://github.com/zeftan-collab/personal-portfolio.git`
2. Open `index.html` in a browser (or use the VS Code *Live Server* extension).

## Project Structure

```
personal-portfolio/
├── index.html
├── style.css
├── script.js
├── images/
└── README.md
```

## Deployment

Hosted on [Vercel](https://vercel.com/) and connected to this GitHub repository. Every push to `main` redeploys the site automatically.
